# Code availability

The custom analysis and figure-generation code is available at
https://github.com/hulab-bnu/collagen-cys-md-analysis under the MIT
License. The repository includes scripts for PyRosetta cysteine screening,
GROMACS trajectory preprocessing, RMSD-Rg free-energy mapping, DCCM analysis,
cross-trimer cysteine sulfur-distance analysis, MM/PBSA analysis and PyMOL
rendering. Large simulation trajectories and derived source-data files are not
stored in the code repository and should be cited through the associated data
record. The version used for publication should be identified by its GitHub
release tag and archived DOI.
